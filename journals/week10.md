Firstly, I shocked myself with my sheer talent and uncompromisable skill. I also got to harness some of the things I worked with in my CART 211 final project as described in my last Highly Engaged Journal Entry, which I'm very happy about because I have fond memories of spending countless hours sitting at the library figuring it out, just as every first-year university student does on a Friday night. 

Astonishingly, the system works pretty much exactly as I intended from the beginning aside from the way it looks. It is meant to run mostly separately from the main web server so that it handles media and other data correctly and can keep its own drafts of seasons before they're ready to be published. Content is stored in its own library that it can fetch from or upload to so that we don't have any duplicated media or broken references. There are also handlers for features that haven't been implemented yet like a dropdown selector for effects and placeholders for audio. An API passes everything between the interface (the front-back-end? the back-front-end? the back-end's front end? the front of the end? the end-back? the front-back?) to the filesystem, which was the most difficult part to get working. I'm pretty sure I got the JSON validation right as well, although it probably could be more comprehensive.
