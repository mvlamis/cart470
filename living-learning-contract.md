**Project Focus**  
Falls / Chutes is an ongoing multimedia digital installation piece exploring themes of collective crisis, intergenerational memory, and mourning through the four seasons. We are tasked with creating a web-based publication that incorporates the imagery, audio, and text of the greater artwork while also providing information about the exhibition. We are encouraged to explore novel ways of accessing and interacting with works online.

**Overall Objectives**

* Elevated web presence for Falls  
* Provide administrative information about installation work  
* Accessible digital presentation/interpretation of multimedia research-creation project 

**Keywords**  
Seasons, Web design, Interaction design, Multimedia, Digital publishing, Digital exhibition, User experience (UX), Accessibility, Visual culture, Art & technology, Photography, Video, Sound, Poetry, Flow, Tangibility, Memory, Grief, Trauma, Emotional Connection, Caregiving, COVID-19, Long-term care, Snakes and Ladders

**Learning Objectives**
1. Analyse existing digital exhibitions and multimedia publications to identify effective approaches to presenting photography, video, sound, poetry, and contextual information in an online environment.  
2. Design and prototype multiple possible structures for a digital publication, using wireframes and Figma to explore navigation, interaction, pacing, and relationships between different media.   
3. Develop a functional web-based publication that implements the selected design and integrates interactive elements and multiple forms of multimedia content.   
4. Evaluate the website through user testing and feedback, identifying and addressing issues related to usability, accessibility, navigation, and the overall experience of interacting with the work. 

**Learning Activities**
1. Research and analysis of digital/multimedia exhibition formats

Review the provided references and other examples of online exhibitions and multimedia publications to identify different ways that photography, video, sound, and poetry can be presented together online. Particular attention will be given to how these works organize navigation, pacing, transitions, and relationships between different media. 

References: 

* McCord Stewart Museum. “Incipit – COVID-19 – Photography Exhibition.” 2022\.  
* Moore, Sam. “The Ritualistic Power of CAConrad’s Poetry.” *Frieze*, 2026\.  
* Ocula. “Wolfgang Tillmans.” 2022\.

Activity outcome: Create a short collection of visual and written notes identifying useful or interesting approaches from these references and how they could translate to this project. 

2. Digital publication and interaction exercises 

Experiment with different ways of organizing the project’s seasonal chapters and multimedia content through sketches, wireframes, and Figma prototypes. Explore how a viewer could move between text, photography, video, sound, and contextual information without making the website feel like a conventional gallery archive. 

Activity outcome: Develop and test multiple possible website structures/navigation systems in Figma before settling on the structure used for the final website. 

3. Web development and implementation

Apply the design decisions from the prototyping stage of the development of a functional website. This will involve building the page structure, implementing navigation and interactive elements, and creating a system that can accommodate the project’s different media formats. Placeholder content will be used initially so that the structure and functionality can be tested before integrating the final project materials.

Activity outcome: Produce a functional website prototype that demonstrates the intended navigation system and can later accommodate the final multimedia content. 

4. Accessibility and user testing

Test the website with attention to readability, navigation, media accessibility, and the overall experience of moving through the work. Make adjustments based on testing and feedback from the team and client. 

Activity outcome: Identify and address usability or accessibility issues before the final presentation of the website. 

**Milestones**  
Milestone \#1  
Our first milestone will be to organize the images and Miro template that was given to us by VK Preston, into a flow-like state that also works for a more technical website. This milestone will allow us to have the aesthetics of the website and know which elements lead to the next element for everything to seamlessly work together.

Activities:

* Follow VK Preston’s vision for the visual components of the website, so we only incorporate the parts they really want to show within the website, and leave out the other elements for their performance.  
* Create an interesting flow of pictures, videos, excerpts, and poetry that feel natural and mold together nicely.  
* Think more about the UX elements of the website for better visual engagement.  
* Get feedback for the visual components of the website before it is properly incorporated into the technical website.

Outcomes:

* Have a flow of working pictures, videos, excerpts, and poems that can be easily transferred into a website template.  
* Have a revised product of the visual elements and aesthetics of the website that fits the emotion and depth of this project.  
* Have a fully functional and usable UX design for the website.

Milestone \#2  
Our second milestone focuses on the technical side of the website, where we will find a website format that would work for its technical components as well as its more visual and abstract components. In this technical portion, the website will only have placeholder text and images.

Activities:

* Work on creating a proper website layout with Figma with all components that are usable and functional.  
* Start transferring our Figma prototype into a website development software so that all that is left is to incorporate the visuals and text.  
* HAve VK Preston and the team test out the website so that everything is easy to use and is understandable.  
* Make the UI elements of the website clear to the team, for easier and doable requests for changes.

Outcomes:

* Have a fully functioning website with only the technical components and placeholders for the text and images.  
* Have VK Preston and the team fully capable of navigating the website and understanding where everything will be.  
* Have a fully functional UI design of the website that everyone understands how to use.

Milestone \#3  
Our last milestone will be to put both the components from the first milestone and the second milestone together.

Activities:

* Put all the pictures, videos, excerpts, and poems into the placeholder spaces on the website.  
* Have the team review everything so that all elements are in their exact spaces and the flow is completely understandable and pleasant.  
* Have the team and VK Preston use the website so that we can see everything that worked separately now work together.  
* Finalize all UX and UI components so that everyone is satisfied.  
* Get prepared to launch the website live.

Outcomes:

* Finalize all elements of the website and have everything completely usable and functional.  
* Have VK Preston and the whole team use the website and navigate it as intended.  
* Teach VK Preston and the team how the website works from the designer’s point of view in case they need to make changes or add new components to the website.  
* Finish the website completely fixing all feedback and make it go live.
